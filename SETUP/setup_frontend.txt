1. INTRODUCTION
===============================================================================

This document explains how to install, configure, and execute the React Native
frontend application of the FoodGuard project.

The frontend is responsible for providing an intuitive and responsive mobile
interface through which users interact with the FoodGuard system. It communicates
with the FastAPI backend using REST APIs and allows users to perform various
operations including user registration, login, food image upload, AI prediction,
nutrition lookup, market price viewing, and prediction history.

The application has been developed using React Native with Expo to ensure
cross-platform compatibility and ease of development.

6. APPLICATION CONFIGURATION
===============================================================================

The frontend communicates with the FastAPI backend using REST APIs.

Locate the API configuration file.

Example

services/api.js

or

constants/config.js

Update the Backend URL.

Example

http://127.0.0.1:8000

For Android Emulator

http://10.0.2.2:8000

For Physical Device

http://YOUR_LOCAL_IP:8000

Example

http://192.168.1.100:8000

Both the mobile device and backend computer must be connected to the same Wi-Fi
network when testing on a physical device.

15. COMMON TROUBLESHOOTING
===============================================================================

Problem

npm install fails

Solution

Delete

node_modules

Delete

package-lock.json

Run

npm install

--------------------------------------------------

Problem

Expo does not start

Solution

Run

npx expo start --clear

--------------------------------------------------

Problem

Application cannot connect to backend

Solution

• Verify backend is running.

• Check API URL.

• Ensure firewall allows port 8000.

• Connect both devices to the same Wi-Fi network.

--------------------------------------------------

Problem

Camera Permission Denied

Solution

Enable Camera Permission from Device Settings.

--------------------------------------------------

Problem

QR Code does not work

Solution

Restart Expo Server

Run

npx expo start --clear

16. DEVELOPMENT NOTES
===============================================================================

The frontend follows a modular component-based architecture.

Reusable components have been separated from business logic to improve
maintainability and code readability.

API communication is centralized within service files, allowing backend URLs
and endpoints to be updated without modifying multiple screens.

Navigation is handled through React Navigation, while authentication state is
managed globally using Context API.

The user interface has been designed to remain simple, responsive, and suitable
for non-technical users.
