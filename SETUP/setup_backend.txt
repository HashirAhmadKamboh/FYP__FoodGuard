1. INTRODUCTION
===============================================================================

This document explains how to install, configure, and execute the backend of
the FoodGuard project.

The backend is developed using FastAPI and serves as the central component of
the FoodGuard system. It is responsible for handling REST API requests,
processing food image predictions using the trained MobileNetV2 model,
managing user authentication, storing prediction history, serving nutrition
information, collecting market prices through web scraping, and communicating
with the SQLite database.

The backend follows a modular architecture, making it easy to understand,
maintain, and extend in future versions.

===============================================================================
8. DATABASE MIGRATIONS
===============================================================================

FoodGuard uses Alembic for database migrations.

Run migrations using

alembic upgrade head

If the database already exists, Alembic will synchronize all tables with the
latest schema.

14. RUNNING THE BACKEND
===============================================================================

Open terminal inside backend folder.

Activate virtual environment.

Run

uvicorn app.main:app --reload

If successful, the terminal displays

Uvicorn running on:

http://127.0.0.1:8000

The API server is now ready to accept requests from the React Native mobile
application.

17. DEVELOPMENT NOTES
===============================================================================

The backend follows REST architecture and separates responsibilities into
routers, services, models, schemas, and utility modules.

Business logic is isolated from API endpoints to improve maintainability,
testing, and scalability.

The modular architecture allows future developers to extend the application
without affecting existing functionality.
